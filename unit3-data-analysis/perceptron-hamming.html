🧮 퍼셉트론과 해밍거리

임곗값을 직접 조절해 논리 게이트를 만드는 퍼셉트론과, 서로 다른 칸의 개수로 패턴을 비교하는 해밍거리를 실습해봅시다.

출력 = 1, 만약 (w1·x1 + w2·x2) ≥ θ, 아니면 0

진리표

XOR, 왜 안 될까?

XOR의 참(1)인 두 점 (0,1),(1,0)과 거짓(0)인 두 점 (0,0),(1,1)은 직선 하나로 절대 나눌 수 없습니다 — 아무리 w1, w2, θ를 바꿔도 4개를 동시에 맞힐 수 없습니다. 아래에서 여러 퍼셉트론을 층으로 쌓아서(다층 퍼셉트론) 해결하는 방법을 확인해보세요.

아이디어: XOR = AND( OR(x1,x2), NAND(x1,x2) ) — OR과 NAND라는 두 퍼셉트론의 출력을 다시 AND 퍼셉트론에 입력합니다.

관찰 포인트

  • 임곗값(threshold) θ는 "이 값을 넘으면 1, 안 넘으면 0"을 가르는 기준점입니다. 가중치가 정해져도 θ를 어디에 두느냐에 따라 결과가 달라집니다.
  • AND, OR처럼 직선 하나로 나눌 수 있는(선형 분리 가능한) 문제는 퍼셉트론 하나로 풀리지만, XOR처럼 그렇지 않은 문제는 여러 층을 쌓아야 풀립니다.

관찰 포인트

  • 해밍거리는 칸이 몇 개 다른지만 세는 아주 단순한 유사도 계산입니다 — 그래서 계산이 빠르고 이해하기 쉽습니다.
  • 노이즈(잡음)를 몇 칸 섞어도 원래 모양과 가장 가까운 기준 패턴으로 잘 분류되는 것을 확인해보세요 — 실제 손글씨 인식도 이런 원리를 응용합니다.
  • 손글씨 숫자 인식(유클리드 거리), 텍스트 유사도(코사인 유사도)에 이어 세 번째 거리 개념입니다. 목적에 따라 다른 거리 개념을 사용합니다.
